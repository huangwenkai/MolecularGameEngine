# MolecularGameEngine

自研 2D 像素游戏引擎 + 横版动作游戏原型（Rust + wgpu）。
玩法方向：**【泰拉瑞亚】+【Noita】+【暗黑破坏神】**——可破坏的像素世界、流畅动作战斗、暗黑式掉落成长，并内置可自编辑的特效 / 人物形象 / 植被编辑器与引擎 IDE。

## 核心特性

- **地形即像素（Noita 式）**：世界以 1 像素为粒度模拟，挖掘 / 建造 / 燃烧 / 腐蚀全部精确到单像素
- **下降沙物理**：粉末 / 液体 / 气体三态、密度置换、材质反应（火遇水化汽、岩浆凝石、酸腐蚀、地形燃烧）
- **悬浮块物理化**：静态地块失去支撑后转为碎屑自然坠落（连通区域检测）
- **光照**：天空光 + 方块光双通道，8 邻接圆形光斑，火把 / 火球 / 发光材质 / 玩家微光，昼夜循环
- **战斗与特效**：三连击动作表、命中帧 / 取消窗口、暴击、击退、顿帧、震屏、伤害飘字；RON 数据驱动特效蓝图
- **暗黑成长层**：物品 / 稀有度五档 / 随机词缀 / 装备属性聚合 / 掉落与合成 / 等级与属性点 / 主动技能
- **怪物与 AI**：5 种怪物 + 多阶段 BOSS、A* 重力可走寻路、精英词缀、网格导航
- **NPC 生活模拟**：饥饿 / 口渴 / 疲劳驱动，找水喝水、找食物进食、回家睡觉、白天工作
- **编辑器与热重载**：F1 特效 / 动画 / 植被 / 人物形象编辑器，F4 引擎 IDE（左中右布局 + 内嵌视口），数据表与着色器改完即时生效
- **全程序化资源**：贴图、音效、BGM、环境音均由代码生成，无外部美术依赖

## 工程结构

```
MolecularGameEngine/
├── crates/
│   ├── mge-core/       数学、随机数、事件总线、日志
│   ├── mge-platform/   窗口(winit)、输入与动作映射、固定步长时间
│   ├── mge-render/     wgpu 渲染器、图集、批处理、Bloom、光照合成、egui 管线
│   ├── mge-sim/        像素物理模拟（下降沙 / 材质反应 / 悬浮块塌落）
│   ├── mge-world/      像素世界、程序化生成、植被、光照、昼夜
│   └── mge-runtime/    引擎装配与主循环（App trait + 窗口/无头驱动）
├── game/               游戏内容层（main/player/monsters/npc/editor/ide/project/skills…）
│   └── assets/         数据表(RON)、动画精灵表、人物形象 PNG
├── assets/             引擎侧数据表(materials/vegetation/actions) 与 WGSL 着色器
├── projects/           游戏工程（素材根，由 IDE 创建/打开）
├── exports/            工程导出副本
├── saves/              存档与设置
├── screenshots/        自测截图产物
└── ROADMAP.md          开发主控文档（里程碑与变更记录）
```

## 构建与运行

前置：Rust 工具链（stable）、Windows 桌面（当前仅支持 Windows）。

```bash
# 窗口模式（正常游玩）
cargo run -p mge-game

# 无头自测：跑完 1350 帧全流程并输出验收截图/结果
cargo run -p mge-game -- --selftest

# 仅编译
cargo build -p mge-game
```

自测截图输出到 `screenshots/`，控制台逐项打印 `[SELFTEST] … PASS/FAIL`。

## 操作

| 操作 | 默认键 |
|---|---|
| 移动 | A / D（或方向键） |
| 跳跃 | W / 空格 |
| 攻击 / 使用工具 | 鼠标左键 |
| 快捷栏 1~8（剑/镐/石块/火把/水/沙/弓/火球） | 数字键 1~8 |
| 主动技能（旋风斩 / 火焰新星 / 治疗术） | Z / X / C |
| 喝药水 | Q |
| 背包 | I |
| 特效编辑器 / 引擎 IDE / 调试面板 | F1 / F4 / F3 |
| 快速存档 / 读档 | F5 / F9 |
| 系统设置（音量、震动、键位、存档位） | ESC |

键位可在 ESC 面板中重绑定，配置持久化到 `saves/settings.ron`。

## 热更新：开着游戏开发

以下内容保存后即时生效，**无需重启**：

- `assets/data/materials.ron`（材质，可加新材质）、`assets/data/vegetation.ron`（植被）
- `game/assets/data/vfx.ron`（特效蓝图）、`weapons.ron`（武器挂接）、`animations.ron`（动画）
- `assets/shaders/*.wgsl`（4 个着色器，编译失败保留旧管线）
- 人物形象（F1 人物页逐像素绘制，实时生效，可保存为 PNG）

需要重新编译才能生效的：Rust 代码，以及编译期嵌入的 `actions.ron`（动作表）与 `items.ron`（物品表）。

## 引擎 IDE（F4）

左中右三段布局：

- **左**：工程（新建 / 打开 / 关闭）+ 素材树（数据表 / 着色器 / 精灵表 / 人物形象 / 存档）+ 场景树（玩家 / 怪物 / 居民 / 训练假人）
- **中**：视口（透明面板透出实时游戏画面，可暂停 / 运行，带昼夜滑块）或文件编辑器（RON / WGSL 文本，Ctrl+S 保存；PNG 像素预览）
- **右**：检查器（实体组件实时属性 / 文件属性与操作）+ 素材工具（精灵表导入向导、工程导出）

工程目录 `projects/<name>/assets/…` 即素材根；打开工程后所有编辑器读写与热重载都作用于工程文件。

## 性能

CPU 版像素模拟在 4096×2048 世界（512 区块）下约 0.6~2.0 ms/逻辑帧（60Hz 预算 16.7ms），静止区块自动休眠；光照重算按脏区配额推进。GPU 版模拟与 GPU 粒子留作后续优化项。
